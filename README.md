# Đào Vàng · Base CRM

Game quiz nhiều người chơi: Đào → Hé chủ đề → Đặt cược → Trả lời → Bảng xếp hạng.

- `host.html`: màn chiếu (tạo phòng, QR, điều khiển, bảng xếp hạng, xuất CSV, đáp án)
- `index.html`: màn người chơi (quét QR, nhập tên, chọn avatar)
- `js/questions.js`: câu hỏi và luật chơi
- `js/config.js`: config Firebase Realtime Database
